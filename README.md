# 🏝️ Git Archipelago

A 3D floating-island village in the browser where every git commit is an autonomous citizen!

## Quick Start

```bash
npm install
npm run dev
```

## Features

- **Floating Branch Islands & Suspension Bridges**: Branches float as distinct sky islands linked at fork and merge commits.
- **Autonomous Commit Citizens**: Builders (`feat`), Bug Catchers (`fix`), Bridge Mayors (`merge`), Lore Scribes (`docs`), and Bonsai Gardeners (`refactor`) stroll, hop, and wave along their branch trails.
- **Local Working-Tree Gate Visitors**: Open any local git repo to see uncommitted file changes waiting outside the Village Gate (1 changed file = 1 visitor in line!).
